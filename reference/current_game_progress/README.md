# Current Game Progress Reference

This folder preserves the fuzzy controller, training loop, experiments, configs,
notebooks, and logs that were in the project before the restart.

The root of the repository now keeps the reusable Asteroids framework:

- `game/`
- `assets/`
- `main.py`

If you want to run one of these archived scripts, run it from the repository
root so it can still import the root `game` package.
